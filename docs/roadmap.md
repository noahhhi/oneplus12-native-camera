# 后续研究待办

以下三项在现有相机修复收尾后推进，当前均为待研究目标，不代表已实现或已确认硬件支持。现有版本仍需补充真实手持运动、长时间录像和 6× 明亮场景验证。

当前最高优先级：定位录像试用版 0.1 在实际使用中的闪退。先保留崩溃证据并明确故障进程，再做单变量复现与回退对照。固件对比可离线并行推进，不能替代稳定性修复。

1. [ ] **动态照片支持 4K Live HDR Photo**
   - 分析原厂动态照片的拍摄、编码、封装及相册播放链路。
   - 对比目标实现中 4K 和 HDR 分别对应静态封面还是动态片段，分别检查实际分辨率、HDR 数据、时序及播放兼容性；不以文件标记作为成功依据。
2. [ ] **大师模式支持 Live Photo**
   - 研究大师模式接入原厂动态照片缓冲、录制与封装链路。
   - 保持已验证的原厂 HDR 照片能力，检查照片与动态片段同步、镜头切换和保存稳定性；分别记录自动与手动曝光的兼容范围。
3. [ ] **Xpan 模式支持 Ultra HDR**
   - 研究 Xpan 模式的原厂 HDR 决策、裁切、色彩处理及增益图保存路径。
   - 验证原厂 HDR 数据来源、有效增益图、宽幅构图及画面质量，回归现有照片模式。

## 固件对比与边界

- 已核实 **Find X10 Pro Max / PMX110**，并直连下载 `17.0.0.115(CN01)` 完整固件，完成校验和第一轮离线对比；详见[参考研究](findx10-reference.md)。
- 优先比较相机应用、相机 SDK、相关系统服务、原生库与能力配置。对比结果不能直接证明一加 12 具有相同的硬件或处理能力。
- 继续沿用原厂原生 HDR 标准，不以 SDR 成片后生成增益图代替原厂 HDR。
- 对比固件仅用于本地分析，不直接跨机型刷入。原厂文件、照片、设备日志及连接信息保持私有，公开仓库仅保存原创工具和去除隐私信息后的结论。
- 真机改动保持可撤销；每次测试后关闭相机，设备工作结束后断开本任务的 ADB TCP 连接。
